UC-12: Apply Tags to Contacts

Actor: Logged-in User
Description: Assign one or multiple tags to a contact.

Features:

Add or remove tags per contact

Maintain relationship between contacts and tags

OOP Concepts:

Methods in Contact class to manage tags

Maintain encapsulation of internal tag collection

Java Concepts:

add() and remove() methods in Set

Loop to display tags

Usage Example:

contact.addTag(new Tag("Work"));
contact.removeTag(new Tag("Family"));
System.out.println(contact.getTags());
