UC-06: Edit Contact

Actor: Logged-in User
Description: Modify existing contact information like name, phone, or email.

Features:

Update single or multiple fields

Validation before changes

Maintain contact consistency

OOP Concepts:

Setter methods with validation

Copy constructor for creating a new version (if needed)

Java Concepts:

Conditional statements

Loops for updating multiple fields

Defensive copying to prevent unwanted changes

Usage Example:

contact.setName("Alice Smith");
contact.addPhoneNumber("67890");
System.out.println("Contact updated: " + contact);
