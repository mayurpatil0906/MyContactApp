UC-05: View Contact Details

Actor: Logged-in User
Description: Users can view complete information for any contact.

Features:

Display all phone numbers and emails

Optional formatting like uppercase or masked email

OOP Concepts:

Getter methods in Contact class

toString() method override for formatted output

Java Concepts:

String formatting

Loops to display multiple items (phones/emails)

Optional for nullable fields

Usage Example:

System.out.println(contact); // Uses toString() to display all info
