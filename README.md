UC-03: User Profile Management

Actor: Logged-in User
Description: Users can update their profile details, change passwords, or manage preferences.

Features:

Update name, email, or password

Input validation for changes

Maintain user state

OOP Concepts:

Setter methods in User class

Encapsulation: private fields with controlled access

Method calls for updating and validating information

Java Concepts:

Input handling

Validation using conditional statements

Exception handling for invalid updates

Usage Example:

user.setName("John Smith");
user.setPassword("newPassword123");
System.out.println("Profile updated: " + user.getName());
